# **🚀 Ultimate Tools**

Добро пожаловать\! Это набор мощных скриптов и утилит для удобного управления, обновления и глубокой диагностики маршрутизации на роутерах с **OpenWrt**, использующих **Podkop** и **Sing-box**.

Главная гордость этого репозитория — **Ультимативный Мега-Анализатор**, который работает как настоящий сетевой инженер: он не просто показывает сухие цифры, а читает логи в реальном времени, находит зацикливания, тестирует туннели и выдает готовые команды для исправления ошибок.

## **⚡ Быстрый старт (Запуск Меню)**

Вам не нужно ничего скачивать вручную. Просто скопируйте эту команду, вставьте её в терминал вашего роутера (через SSH или встроенный терминал) и нажмите Enter:
```bash
sh <(wget -qO- https://maznevpaul-lgtm.github.io/openwrt-scripts/menu.sh)
```

## **🛠 Что внутри?**

Запустив команду выше, вы попадете в **Главное меню (v1.2)**, где собраны все самые необходимые функции:

**1\) 🚀 Запустить Мега-Анализатор** — Полная и глубокая диагностика вашей сети.

**2\) 🧹 Очистить кэш DNS и перезапустить Подкоп** — Быстрое решение проблемы "залипших" сайтов.

**3\) 🔄 Обновить Подкоп** — Вызов официального скрипта обновления без сброса настроек.

**4\) 🚀 Запустить диагностику от RouteRich** — Вызов альтернативного сканера конфигурации.

**5\) 📦 Обновить Sing-box Extended** — Автоматическое обновление ядра Sing-box.

## **🔍 Подробнее о Мега-Анализаторе (v37)**

Выбор первого пункта в меню запускает podkop\_analyzer.sh — продвинутый скрипт, который проверяет систему от и до:

* **Мониторинг служб:** Проверяет статусы podkop, zeroblock, zapret, sing-box и предупреждает об их конфликтах.  
* **Умный анализ DNS:** Детектирует подмену FakeDNS и учитывает сложную архитектуру DNS Failsafe Proxy (порт 53).  
* **Тест скорости узлов:** Опрашивает API Sing-box и проверяет реальный отклик от ваших VPS и туннелей (Vless, AWG и др.).  
* **Live Log Scanner (Чтение логов):** Анализирует системный журнал в реальном времени\! Находит причины таймаутов (i/o timeout), падений прокси (connection refused) и ошибки кэша (missing fakeip record), сразу подсказывая решения (например, снизить MTU).  
* **Защита от зацикливаний:** Проверяет интерфейсы WireGuard/AmneziaWG на наличие "паразитных" маршрутов и петель маршрутизации (Routing Loops).  
* **Функция Auto-Fix:** Если скрипт находит критическую ошибку, он генерирует готовую команду — вам остается только скопировать её и нажать Enter, чтобы роутер сам себя починил.  
* **Системная статистика:** В конце отчета выводится удобная сводка: аптайм, нагрузка на процессор, температура, состояние оперативной памяти и количество активных Wi-Fi клиентов.
